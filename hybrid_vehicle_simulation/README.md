# 하이브리드 차량 동적 성능 시뮬레이터 (GUI 버전)

## 프로젝트 설명

본 프로젝트는 하이브리드 차량의 상세 제원을 기반으로 동적 성능을 예측하고 분석하는 Python GUI 애플리케이션입니다.
사용자 친화적인 그래픽 인터페이스를 통해 차량 제원을 쉽게 입력하고, JSON 파일로 저장하거나 불러올 수 있습니다.
시뮬레이션을 통해 차량의 가속 시간 (다양한 구간), 최고 속도 (다양한 모드 및 경사 조건), 등판 능력 등 고급 성능 지표를 계산하고,
주요 결과를 그래프로 시각화하여 제공합니다.

## 프로젝트 구조

-   `hybrid_vehicle_simulation/`: 프로젝트 루트 디렉토리
    -   `main_gui.py`: 시뮬레이션 실행을 위한 메인 GUI 애플리케이션 스크립트.
    -   `main.py`: (선택 사항) 기존 콘솔 기반 실행 스크립트 (GUI 버전 개발로 인해 주요 업데이트는 없을 수 있음).
    -   `src/`: 핵심 소스 코드가 위치한 디렉토리.
        -   `core.py`: 차량, 엔진, 모터, 변속기, 배터리 등 핵심 구성 요소 클래스 정의.
        -   `simulation.py`: 가속, 최고 속도, 등판 능력 등 시뮬레이션 로직 구현.
        -   `outputs.py`: 시뮬레이션 결과 포맷팅 및 데이터 생성 함수 (가속도 맵 데이터 등).
        -   `plotting.py`: Matplotlib를 사용한 그래프 생성 함수 (한글 폰트 지원 포함).
    -   `data/`: 시뮬레이션에 사용될 데이터 파일 (예: 토크 커브 CSV).
        -   `sample_engine_torque.csv`: 샘플 엔진 토크 커브 데이터.
        -   `sample_motor_torque.csv`: 샘플 모터 토크 커브 데이터.
    -   `tests/`: 단위 테스트 코드가 위치한 디렉토리.
        -   `test_core.py`: `core.py`의 클래스들에 대한 단위 테스트.
        -   `test_simulation.py`: `simulation.py`의 함수들에 대한 단위 테스트.
    -   `README.md`: 본 프로젝트 설명 파일.

## 요구 사항

-   Python 3.7 이상
-   필수 라이브러리:
    -   `pandas`
    -   `matplotlib`
    -   `numpy` (일반적으로 pandas 또는 matplotlib의 의존성으로 함께 설치됨)
    -   `tkinter` (Python 표준 라이브러리로 대부분의 Python 설치에 포함되어 있음)

## 실행 방법

### 1. GUI 애플리케이션 실행

프로젝트 루트 디렉토리 (`hybrid_vehicle_simulation/`)에서 다음 명령을 실행합니다:
```bash
python main_gui.py
```
GUI 창이 나타나면, 차량 제원을 입력하거나 저장된 제원 파일을 불러온 후 "시뮬레이션 실행" 버튼을 클릭하여 결과를 확인하고 그래프를 생성할 수 있습니다.

### 2. 단위 테스트 실행

프로젝트 루트 디렉토리 (`hybrid_vehicle_simulation/`)에서 다음 명령을 실행하여 모든 테스트를 실행합니다:
```bash
python -m unittest discover tests
```
특정 테스트 파일만 실행하려면 (예: `test_core.py`):
```bash
python -m unittest tests.test_core
```

## 주요 기능 및 출력

### GUI 입력 파라미터 확장:
-   차량 기본 제원 (질량, 공기저항 등)
-   엔진/모터 토크 커브 CSV 경로
-   기어비 및 최종 감속비
-   **공통 변속 RPM (엔진 기준)**
-   **변속 시간 (초)**
-   **도로 경사도 (%)**
-   **등판/견인 추가 중량 (kg)**
-   **구동계 전체 효율 (%)**
-   **최대 허용 총 토크 (Nm)** (엔진+모터 합산 토크 상한)
-   제원 저장 및 불러오기 기능 (JSON 형식)

### 시뮬레이션 결과 (GUI 결과창 및 콘솔):
-   **가속 시간 (현재 입력된 경사도 적용)**:
    -   0-60 km/h, 0-80 km/h, 0-100 km/h, 0-120 km/h
    -   80-120 km/h (계산됨)
    -   변속 시간의 영향이 가속 시간에 반영됨.
-   **최고 속도**:
    -   평지 하이브리드 모드
    -   평지 엔진 단독 모드
    -   **입력 경사도에서의 등판/강판 최고 속도 (하이브리드 및 엔진 단독 모드)**
-   **등판 성능**:
    -   **발진 가능 최대 구배 (%)**
-   모든 텍스트 결과는 한국어로 제공됩니다.

### 시각화 그래프 (버튼 클릭으로 개별 창에 표시, 한글 지원):
-   속도 vs 시간 (시뮬레이션 최고 속도까지 전체 범위 표시)
-   토크 vs RPM (엔진, 모터, 결합 토크 및 기어 변속 지점)
-   파워 vs RPM (엔진, 모터, 결합 파워 및 기어 변속 지점)
-   기어별 최대 가속도 맵:
    -   Y축 단위 'g' (중력가속도)로 표시.
    -   X축(차속) 시작점이 각 기어의 유효 RPM(예: 1000 RPM) 기준으로 조정됨 (출력 로직에 따라).

## 출력 언어
GUI 및 터미널의 주요 정보와 결과는 한국어로 제공됩니다. 그래프의 레이블 및 제목도 한글을 지원합니다.
